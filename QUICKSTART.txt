SIGMOND APPLIANCE @@VERSION@@ — QUICK START
===========================================
1. Write the image to a USB stick (>=16 GB).  The image is published
   UNCOMPRESSED — there is nothing to decompress, just write it:
     sudo dd if=sigmond-appliance-@@VERSION@@-*.img of=/dev/sdX bs=4M \
             oflag=direct conv=fsync status=progress
   Verify the stick took a real image before booting — this should say
   "DOS/MBR boot sector":
     sudo file -s /dev/sdX
2. Have the RX888 (and GPSDO etc.) ALREADY CONNECTED to the target
   machine, then boot it from the USB.
   Proxmox VE installs AUTOMATICALLY — this ERASES the machine's NVMe disk.
3. When the machine POWERS ITSELF OFF (~3 min), that is your cue:
     REMOVE THE USB STICK, then power the machine back on.
   (The power-off is deliberate: it prevents the installer from
    running again on firmwares that always boot USB first.)
4. The machine boots Proxmox from its own disk. When the console says
   "plug in the Sigmond install USB", insert the SAME stick again.
   The decoder VM (VMID 100) imports automatically (~3 min), sized to
   this machine (all CPUs minus one pair, RAM minus 2 GB).
5. The site setup wizard appears on the console (LEAVE THE STICK IN):
   enter your reporter ID (e.g. AC0G/B4), grid square, optional
   antenna and remote access (RAC).
   Rerun any time with:  sigmond-setup --reconfigure
6. After the wizard, the host tunes itself automatically: CPU
   isolation + pinning (grub), USB controller passthrough to the VM.
   The console then says REMOVE THE USB STICK. Do it. The machine
   reboots itself into production (decoder VM autostarts, pinned,
   with the RX888 passed through).
   NOTE: after this reboot the host console keyboard may be dead —
   the USB controllers now belong to the VM. That is normal; use ssh.
7. Proxmox web GUI: https://<machine-ip>:8006
   Host login: root / hamsci-sigmond   (change it!)
   Decoder VM login: hamsci / hamsci-sigmond   (ONE password everywhere; change it!)

This stick is appliance version @@VERSION@@. Before the wizard runs, the
Proxmox host is named sigmond-appliance-@@VTAG@@ and the VM
sigmond-decoder-@@VTAG@@ (so you can tell which image a machine came
from); the wizard then renames them to your station designator — VM =
designator (e.g. AC0G-B4), Proxmox host = designator-PM (AC0G-B4-PM).
The image version stays visible in /etc/sigmond-appliance/version and
the login panel.

RETURNING STATION? (key restore)
  If this replaces an existing Sigmond station, its registered PSWS/upload
  keys can ride the stick so no portal re-registration is needed:
  1. On the OLD station (or from a backup):
       tar czf site-keys.tar.gz -C / etc/hs-uploader/keys home/timestd/.ssh
  2. AFTER burning this stick, it shows one small FAT volume (the EFI
     partition) on any Mac/Windows/Linux machine — copy site-keys.tar.gz
     onto it and eject.
  3. Install normally. The wizard restores the keys and runs the PSWS
     verify automatically.
