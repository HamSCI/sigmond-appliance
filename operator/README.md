# Operator shell conveniences shipped with the appliance

Small, opinionated defaults that make a station pleasant to work on. None of
them affect measurement; all of them are idempotent and non-fatal.

## `toprc` — the CPU column in `top`

Puts **`P`** (last-used CPU) immediately after `%CPU`:

    PID USER  PR NI  VIRT  RES  SHR S  %CPU P  %MEM   TIME+

Stock `top` omits it entirely. On this fleet that column is not cosmetic:
radiod is pinned to one hyperthread sibling pair, decoders to the remaining
cores, and "is this process on the core it is supposed to be on?" is a
question asked constantly — while chasing affinity, checking a `taskset`
took, or working out why a box is loaded. Without `P` the answer needs a
separate `ps -o psr` every time.

Installed to `~/.config/procps/toprc` (the modern path; `~/.toprc` is the
legacy one and `top` prefers the former) for every operator account on both
planes. An existing file is never overwritten — a hand-tuned config is
someone's work.
